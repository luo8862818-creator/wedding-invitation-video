# 视觉与素材

人物母版已由用户确认；双人透明 PNG、单人 PNG 均引用母版生成。背景单独生成，中文全部是 HTML。采用樱花蓝天、奶油纸张、粉色花园与黄昏烟花；照片拼贴、日期、流程、人物近景采用不同构图。真实照片和婚礼细节图片保留上传位置。

生成工具：内置 image_gen。完整基准提示词见根目录 IMAGE_PROMPTS.md。生成时未添加姓名、日期或酒店。母版保存在 assets/images/characters/couple-character-master.png；人物封面为 couple-cover-pose.png。背景保存在 assets/images/backgrounds。单人图和双人图已检查 RGBA alpha 通道。

首版复用主背景于相近场景，爱的细节及宾客提示使用纸张装饰。未采用生成失败的带有不同人物的结尾图；重新生成了无人黄昏花园以维持角色一致性。没有使用用户未授权音乐。
