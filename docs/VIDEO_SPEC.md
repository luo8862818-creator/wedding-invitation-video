# 视频规格

最新网页和视频共用 `src/scenes.js` 生成的 12 个页面。每页结束前 1.25 秒向上滑动，下一页从下方进入；HyperFrames 在当前场景内绘制下一页的过渡预览，host 时间段保持连续无重叠。网页以同一组起始时间自动驱动纵向场景条，手机端适配视口大小。根目录 `index.html` 仍是视频合成，`invitation.html` 才是面向宾客的展示网页。

1080×1920，30 FPS，120 秒，3600 帧。时间段：0–8、8–16、16–26、26–36、36–48、48–58、58–70、70–82、82–94、94–102、102–112、112–120。

每个 scene host 与 scene root 和 timeline 使用同一 ID。场景内容在 template 内，root timeline paused，动画使用确定性的 GSAP 时间，不运行随机数或墙钟。配置在 Node 构建时编译为静态文本和媒体路径；最终渲染无需 API。

主标题 76–104 px，正文 34–48 px，提示至少 28 px。内容左右安全边距 110 px，顶部约 170 px。人物图片 1020 px 高，入场 1.1–1.2 秒，图片逐个间隔 0.22 秒，轻微推进 4.5%。封面、人物、拼贴、日期、流程、地点、信笺与结尾有独立构图。

用户信息空值不替换为假数据。音乐文件未上传时静音。正式导出等待用户验收。
